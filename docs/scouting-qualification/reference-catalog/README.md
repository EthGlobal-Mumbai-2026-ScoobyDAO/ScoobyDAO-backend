The replay should first pin incident block and chain ID; independently retrieve the transaction receipt, token and pool bytecode, relevant state and source bytes at that block; distinguish individual liquidity-removal events from net losses; and preserve claims and contrary accounts. Separately inspect present-day code, ownership, liquidity and sell behavior before making any current assertion. Never promote a historical reference directly into the normal fresh-discovery gate. The Ethereum Anubis and Base Magnate cases are useful contrasting protocol references but do not establish ERC-20 sell restrictions.
