## Smallest executable integration path

1. Import a candidate and record separate human selection or explicit scoped exception. Snapshot selection/admission identity and hashes; do not accept a claimed qualification without the verified gate.
2. Create a stable run ID and five independently idempotent persisted pillar tasks. Each reads bounded immutable evidence references, writes results or an explicit unavailable/error, and exposes retry/cancellation progress. Producer calls and state transitions need fencing before external side effects.
3. Validate identity, source paths/hashes, cross-references and exact report bytes against frozen v0.2; bind `scooby.pillar-tldr/1`, `scooby.pillar-irc/1`, `scooby.reasoning/1` and `scooby.validation-audit/1` only when supported by agreed producers/consumers. Unknown profiles are not silently treated as validated. Keep synthesis neutral; application-owned tools call Terra only via requested Chat Completions, under separately authorized budget. The newer research prototype uses Responses and cannot be dropped in unchanged.
4. Build the reviewed IRC reader against the same version and digest; expose local draft, complete source-linked Markdown and full PDF with chart/source integrity and all-page verification. An HTML browser print of collapsed content is not the full PDF.
5. Compare a locked draft to independent mechanism evidence; request human review. Preserve revision invalidation; do not claim authenticated sign-off or publish.

The reference track additionally imports a source-curated bundle and serves validated IRC/HTML/Markdown/PDF artifacts; it does not complete live research. `GET /readiness/honeypot` exposes a static integration inventory. It performs no source or model calls and is not a dynamic health probe, a claim that other worktrees are integrated, or case admission. In this checkpoint no paid calls or candidate HTTP/RPC requests were performed by backend. No frozen schemas changed. The discovery verifiers are not wired to the backend worker; the corrected reader is integrated for imported reference bundles, not automated research.

## Mechanism profile reconciliation

Investigation's proposed `scooby.mechanism-observations/1` and frontend's proposed `scooby.scenario-observation/1` diverge. Investigation is leading a single draft profile/mapping for frontend review; neither is accepted or wired. A claimed boolean or matching sequence ID does not prove a coherent buy-then-sell: bind captured successor state or trace and normal execution controls. Experimental two-wallet/two-run coverage is not an approved admission or assessment policy. A successful sell is scoped counterevidence and can coexist with selective restrictions. Do not automatically generate an avoid warning from these fields.
