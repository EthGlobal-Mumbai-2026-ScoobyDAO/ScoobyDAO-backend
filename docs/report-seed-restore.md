# Local report seed restore

This is an explicit offline CLI, not an HTTP route. Copy a trusted seed ZIP and its independently supplied manifest SHA-256 into a private container location. Set SCOOBY_DATA to the persistent volume directory and SCOOBY_REPORT_RELEASE=approved; the CLI fails closed unless the release policy is explicitly approved-only. Keep that setting for the API as well. Run `python seed_restore.py <seed.zip> --manifest-sha256 <sha256> --report-id <id>` and repeat `--report-id` to select more entries. The manifest digest for the 2026-11-06 snapshot is 13bf0943a2a26b50e2cc3709825a2d59dbe8182ca632f79fb1eb4fc795ae190a; a digest alone is not a signature or proof of reviewer approval.

The command verifies the manifest, candidate and report/asset hashes, identities, pending status and diagnostic synthetic lineage, then installs immutable report versions and queues renders. It creates no research job, World authorization, case decision, sign-off or publication. It labels diagnostics as user-requested historical pending review and source-curated references separately. The ASE locally edited provenance is retained, but the archived seed by itself does not prove the original report or review. It does not restore the original decision/attempt ledger, Terra raw responses, or authenticated approval. Back up the database and seed before import.

Run a worker using the same SCOOBY_DATA persistent volume and zero model/source budgets, e.g. `python -m huey.bin.huey_consumer worker.huey -w 1 -q`; the current Render blueprint starts only the API, so queued renders otherwise remain queued. Configure a worker explicitly before deployment. Never place the private seed in the image or Git. Public access and separate admin review depend on the merged release boundary, not this seed CLI.

Local isolated verification: restored the actual ZIP twice (8 unique entries), rejected an altered report and a bad manifest digest into an empty test database, reopened the database and rendered all eight with the worker. No production deployment or paid calls occurred.
