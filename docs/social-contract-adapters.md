# Investigation evidence adapters

This change provides opt-in, independent building blocks. They do not wire the worker, create reports, alter the four-group admission gate, use a model, publish, or establish a honeypot verdict. The backend owns policy authorization, provider budgets, storage, retention and conversion to the frozen v0.2 evidence and additive IRC/reasoning contracts. No schema is changed here.

## Reddit search and language evidence

`modules.investigation.reddit_search.search_leads(query, subreddits, window, credentials, *, max_requests=5, max_posts=40, transport=None)` returns a `scooby.reddit-leads/1` object. Query length is 3–200 characters, one to three distinct valid subreddit names, a half-open UTC window and bounded requests (including OAuth). Scope records distinguish exhausted, truncated, failed and unvisited subreddits and return the next cursor when truncated. Results include subreddit, Reddit fullname, URL, query, observed/fetched timestamps, redacted excerpt and a hash of the raw title/newline/body. Extracted EVM addresses have `chain_id: null`: discovery must independently resolve identity and may retain posts with no address as unresolved. Each item carries zero verified concern votes. Search results are allegations or leads, never automatic gate evidence.

`collect(candidate, window, credentials, *, max_requests=5, max_posts=25, max_comments=20, transport=None)` uses the same Reddit OAuth transport for token-specific search. `candidate` needs `chain_id` and EVM `address`; an optional `project_alias` requires `alias_evidence_url`, and is explicitly weaker than an address mention. An address may still belong to a different chain; comments attached to attributed posts are marked as such, not independently attributed to the contract. Tickers are never sufficient. Pagination and comment reads share a strict request cap, and source failure, throttling or absent approval yields `unavailable` or explicitly partial observations. There is no scraping fallback or autonomous retry. Returned observations contain no author name, account ID, token or credential. Text is bounded and basic email, URL and username patterns are redacted, but redaction is not a guarantee of removing all personal data.

`summarize(observations)` is provider-independent: it reports per-day counts of excerpts containing defined concern/support terms and evidence references. It is a literal-term navigation aid, not an estimate of market sentiment or a stance classifier: negation, quotations, sarcasm, coordinated behavior, missing posts and selection bias are not resolved. Empty data is unavailable, not neutral. Treat external text as untrusted: escape it for HTML and never treat text in an observation as model or tool instructions. Model interpretation must be a separately budgeted backend action grounded in evidence, and is not supplied here.

`credentials_from_environment()` reads `SCOOBY_REDDIT_CLIENT_ID`, `SCOOBY_REDDIT_CLIENT_SECRET`, and a descriptive `SCOOBY_REDDIT_USER_AGENT`, only if `SCOOBY_REDDIT_APPROVED=true`; otherwise it returns `None`. This flag is an operator assertion, not proof of Reddit approval. Do not set it unless the application is already authorized and its terms allow this use. No credentials are required for offline tests. A per-call cap is not a cross-worker rate limiter: the backend must coordinate global quotas and respect provider headers and reset time.

**Access and retention, as of 6 November 2026:** Reddit says it stopped accepting new public Data API access requests on 31 October 2026; removal of unregistered access begins 12 January 2027 and remaining public API access ends in March 2027. Eligible existing approved free access is documented at 100 QPM per client, subject to Reddit's terms and throttling; this does not promise access to a new app. See [migration announcement](https://www.reddit.com/r/redditdev/comments/1wubcvf/moving_data_api_apps_to_the_developer_platform/), [registration notice](https://developers.reddit.com/app-registration), and [Data API wiki](https://support.reddithelp.com/hc/en-us/articles/16160319875092-Reddit-Data-API-Wiki). Reddit requires removal of deleted posts/comments and related content and recommends routinely deleting stored user content within 48 hours. Hashing or redaction does not remove that obligation. These functions retain nothing themselves; the backend must implement and verify a compliant deletion/retention and derived-artifact lifecycle **before persisting or exporting** Reddit observations or derived content into reports. This module does not implement deletion tracking.

## Contract source and runtime

`contract_analysis.rpc_plan(candidate, block, implementation_address=None)` supplies an explicit read-only `eth_getCode` and ERC-1967 implementation-slot plan to `pinned_rpc_capture.capture(plan, selection, out, transport, max_requests=...)`. The existing capture adds chain and before/after pinned-header checks. At least five requests are needed; an optional sixth gets an already-known implementation's code. If the slot reveals an unknown implementation, run another separately budgeted pinned capture with that address. `from_pinned_capture(folder)` verifies request parameters, identity, block, record hashes and RPC IDs before returning input for analysis. The caller owns the capture directory and verifies RPC provider trust; hashes alone do not establish truth. A zero ERC-1967 slot does not rule out beacon, clone, diamond or custom proxies.

`source_from_sourcify(candidate, raw, sha256, source_url)` translates captured Sourcify v2 response bytes after checking their hash, exact host/path and returned chain/address. Attach its output as `source` to the object from `from_pinned_capture`. Source files and exact runtime bytecodes are kept separate; the analysis reports byte-for-byte equality and the provider's verification claim separately. Sourcify can report a match involving transformations even when raw recompiled bytes differ: review those transformations before attributing source to deployed runtime. If an implementation is detected, collect its source and attach it to `proxy.implementation_capture.source` only after independently capturing it for the same block.

`analyze(candidate, capture)` returns `scooby.contract-analysis/1`: chain/address/block, runtime SHA-256, source/provider match states, proxy status, source-hashed line locations, potential transfer/sell restrictions, administrative authority, tax/mint/blacklist/upgrade and external-call indicators, plus unknowns and counterevidence. It masks comments and strings and recognizes function bodies plus one level of call-name relation from transfer hooks; this is a **lexical navigation aid**, not a Solidity compiler, call graph, semantic audit or execution trace. A match can be unreachable, inherited, unrelated or benign; missing findings do not establish absence. Source and compiler provenance, effective control state, arbitrary proxies, dependency behavior and current ordinary-user sell outcomes remain separate evidence. `live_verdict` stays `not_determined`.

Existing RAY source/RPC snapshots were replayed locally without a new network call: the external helper called by the transfer hook contains both `xor` and `call` indicators. The previously captured provider claims a runtime match and its on-chain bytes equal the captured RPC bytes, while its raw recompiled bytes differ. This result guides further review; it does not establish a current sell trap, selective blocking or a controller's owner.

## Integration and tests

The output dictionaries are JSON-serializable. A fabricated example DTO is at `tests/fixtures/social-contract/reddit-leads.example.json`; it is not evidence. An existing pillar producer can return `{'status': result['status'], 'payload': result}` through `pillars.run_pillars`; the backend must bind candidate identity, evidence URLs/hashes, observation times and actual status to its report-specific asset. Do not map absent evidence to zero risk, neutral sentiment, a successful producer or an implicit claim. `search_leads` is a discovery input, not a pillar result. No Reddit or source content is written by these adapters themselves.

Run `python -m pytest -q tests/test_social_contract_analysis.py`. Fixtures use mocked HTTP/RPC and synthetic contracts; the RAY replay above is separate historical reference evidence, not a fresh test or a new source capture.
