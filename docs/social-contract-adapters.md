# Investigation evidence adapters

This change provides opt-in, independent building blocks. They do not wire the worker, create reports, alter the four-group admission gate, use a model, publish, or establish a honeypot verdict. The backend owns policy authorization, provider budgets, storage, retention and conversion to the frozen v0.2 evidence and additive IRC/reasoning contracts. No schema is changed here.

## Reddit search and language evidence

SearchApi is the selected source; there is no implicit fallback or direct-Reddit OAuth prerequisite. The shared boundary is `modules.investigation.reddit_search.search_leads(query, subreddits, window, credentials, *, max_requests=1, max_posts=40, time_period='any_time', cancelled=None, transport=None)` and returns `scooby.reddit-leads/1`. Candidate context uses `collect(candidate, window, credentials, *, max_requests=1, max_posts=25, max_comments=20, subreddits=None, time_period='any_time', cancelled=None, transport=None)` and returns `scooby.reddit-evidence/1`. Both use the same SearchApi transport. Obtain the explicit provisional 365-day window from `modules.investigation.searchapi_reddit.social_window(days=365)`; each observation includes its date, age and `dated_social_context` source mode. Older discussion is context, not a fresh incident. On-chain freshness and the four-verified-group gate are unchanged.

`reddit_search.credentials_from_environment()` reads the server-side `SEARCHAPI_API_KEY` from the process environment. Its object has a redacted representation. Never pass it to browser code, print it, put it in URLs or check it into a repository. SearchApi requests use a fixed HTTPS host, Bearer header and no redirects. No poller starts on import or merely because a key exists. Each page counts against the explicit call budget; the default is one request. Caller supplies scoped authorization, allowlisted subreddits, cancellation and cross-worker budget/rate controls. The provider's next-page token is opaque, source-specific and only transient. See [SearchApi's Reddit search API](https://www.searchapi.io/docs/reddit-search-api).

The provider supplies titles and sometimes matching-comment snippets, not full post bodies or comment trees. The adapter checks the exact requested half-open timezone-aware window locally, validates Reddit URL, post ID and subreddit, rejects missing/future/out-of-window dates, deduplicates posts and records excluded counts and scope status. Results retain unresolved EVM address mentions with no chain assignment and zero verified concern votes; ticker, subreddit or text cannot prove identity or allegations. Credential, provider, rate, timeout, malformed response and pagination failures remain distinct and never return reflected provider errors. Empty observations are not neutral sentiment. Source text is redacted and limited but redaction is not a guarantee of removing all personal data. Excerpt hashes refer to redacted text, not original content.

`summarize(observations)` is provider-independent: it counts configured words in supplied excerpts by day and lists associated source references. It is a literal-term navigation aid, not a stance classifier or estimate of market sentiment; negation, quotation, sarcasm, manipulation and selection bias remain unresolved. Actual model interpretation is separately authorized and budgeted. HTML consumers must escape text; no model should treat retrieved text as instructions.

**Lifecycle:** Content and its derivatives are transient; no raw responses, author data or provider errors are written by these adapters. Before persisting excerpts, links, hashes or conclusions, the backend must implement and review applicable deletion, expiry and derived-artifact handling. A provider credential does not establish permanent-content rights. [Reddit's Data API guidance](https://support.reddithelp.com/hc/en-us/articles/16160319875092-Reddit-Data-API-Wiki) requires removal of deleted content and related material and recommends routine deletion within 48 hours; review the applicable SearchApi terms too. Do not silently embed social content into immutable report evidence. The retained direct-Reddit OAuth adapter is only available explicitly as `search_leads_reddit_oauth` / `collect_reddit_oauth` for previously authorized apps; no automatic fallback. Reddit says new public API access requests stopped 31 October 2026 and remaining public API access ends March 2027.

**Measured checks, 6 November 2026:** a separate SearchApi smoke returned seven posts outside a 31-day window, so zero were fresh. A subsequent one-page 365-day scouting call returned seven dated context posts (2025-11-14 through 2026-09-26), all unresolved and zero gate votes; further pages were not requested. A one-page candidate-specific RAY call returned HTTP 200 with a provider-declared error or non-success status, so sentiment stayed unavailable; the provider error text was not retained and its exact cause, including whether it indicated no results, is unknown. A third call for rugpull in CryptoCurrency returned seven additional unresolved dated context posts from 2026-04-14 through 2026-09-10; its next page was not requested. These are access/normalization checks, not live token findings. No raw titles, authors or hashes were saved in the metadata handoffs.

## Contract source and runtime

`contract_analysis.rpc_plan(candidate, block, implementation_address=None)` supplies an explicit read-only `eth_getCode` and ERC-1967 implementation-slot plan to `pinned_rpc_capture.capture(plan, selection, out, transport, max_requests=...)`. The existing capture adds chain and before/after pinned-header checks. At least five requests are needed; an optional sixth gets an already-known implementation's code. If the slot reveals an unknown implementation, run another separately budgeted pinned capture with that address. `from_pinned_capture(folder)` verifies request parameters, identity, block, record hashes and RPC IDs before returning input for analysis. The caller owns the capture directory and verifies RPC provider trust; hashes alone do not establish truth. A zero ERC-1967 slot does not rule out beacon, clone, diamond or custom proxies.

`source_from_sourcify(candidate, raw, sha256, source_url)` translates captured Sourcify v2 response bytes after checking their hash, exact host/path and returned chain/address. Attach its output as `source` to the object from `from_pinned_capture`. Source files and exact runtime bytecodes are kept separate; the analysis reports byte-for-byte equality and the provider's verification claim separately. Sourcify can report a match involving transformations even when raw recompiled bytes differ: review those transformations before attributing source to deployed runtime. If an implementation is detected, collect its source and attach it to `proxy.implementation_capture.source` only after independently capturing it for the same block.

`analyze(candidate, capture)` returns `scooby.contract-analysis/1`: chain/address/block, runtime SHA-256, source/provider match states, proxy status, source-hashed line locations, potential transfer/sell restrictions, administrative authority, tax/mint/blacklist/upgrade and external-call indicators, plus unknowns and counterevidence. It masks comments and strings and recognizes function bodies plus one level of call-name relation from transfer hooks; this is a **lexical navigation aid**, not a Solidity compiler, call graph, semantic audit or execution trace. A match can be unreachable, inherited, unrelated or benign; missing findings do not establish absence. Source and compiler provenance, effective control state, arbitrary proxies, dependency behavior and current ordinary-user sell outcomes remain separate evidence. `live_verdict` stays `not_determined`.

Existing RAY source/RPC snapshots were replayed locally without a new network call: the external helper called by the transfer hook contains both `xor` and `call` indicators. The previously captured provider claims a runtime match and its on-chain bytes equal the captured RPC bytes, while its raw recompiled bytes differ. This result guides further review; it does not establish a current sell trap, selective blocking or a controller's owner.

## Integration and tests

The output dictionaries are JSON-serializable. A fabricated example DTO is at `tests/fixtures/social-contract/reddit-leads.example.json`; it is not evidence. An existing pillar producer can return `{'status': result['status'], 'payload': result}` through `pillars.run_pillars`; the backend must bind candidate identity, evidence URLs/hashes, observation times and actual status to its report-specific asset. Do not map absent evidence to zero risk, neutral sentiment, a successful producer or an implicit claim. `search_leads` is a discovery input, not a pillar result. No Reddit or source content is written by these adapters themselves.

Run `python -m pytest -q tests/test_social_contract_analysis.py`. Fixtures use mocked HTTP/RPC and synthetic contracts; the RAY replay above is separate historical reference evidence, not a fresh test or a new source capture.
