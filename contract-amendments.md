## Accepted: additive `reference` in `scouting-case-list/2` (7 November 2026)

For `scooby.reference-display/1` (`docs/reference-display-contract.md`), `schemas/runtime/scouting-case-list-v2.schema.json` now allows each case's `reference` to be `null` (every non-reference case, unchanged) or exactly `{kind: "historical_reference", label: "Historical reference — unreviewed", reports: [{report_id, report_version, report_sha256, association: "historical_reference", review_state, world_verified, gate_effect: "none"}]}` with `additionalProperties: false` throughout. This is backward compatible for producers (null still validates) and additive for consumers; `schema_version` stays `scouting-case-list/2`. Conformance: `tests/test_reference_display.py::test_case_list_carries_reference_objects_and_validates` validates every `/scouting/cases` item, reference and non-reference, against the schema. The frozen candidate 0.1 / report 0.2 schemas are unchanged.
