# Opt-in bounded discovery collection

`bounded_scout.run_once(db, root, enabled=False, budget=0, hourly_limit=0, limit=5, chains=('ethereum','base'))` is disabled by default. A configured caller passes `enabled=True`, integer budgets 1–30 and existing service-owned paths. The function collects through `live_pilot.run` only: it does not run the additional security refresh, LP, archive-RPC or model collectors. The budget covers all requests that this cycle actually sends; a separate rolling-hour cap covers reservations made through this same discovery DB. Reservations are persisted before transmission and count even when a process exits or a request fails. A provider returning 429 is durably held for one hour; redirects and non-allowlisted hosts are rejected.

An exclusive SQLite runner lock prevents overlapping cycles for the same DB, and cycle starts are persisted with a five-minute minimum interval, including interrupted cycles. The integrated worker provides recurring wake-up and local reconciliation when explicitly configured. Operators must provide persistent private storage and monitor disabled, configuration and error states. This module does not change the human or automatic gate. Rollback is to disable the caller; retain the budget ledger across restarts.

The cap is per discovery DB, not account-wide across other applications or DBs. Coordinate a shared provider budget before running multiple deployments. This is a limited new-pool-based source, not exhaustive coverage or a verified safety result. Missing observations and provider errors are unknown; provider hints do not vote. Existing standalone `continuous_pilot.cycle` uses different budgets and is not made safe by this module.

The integrated Huey worker can schedule this path when the explicit `SCOOBY_SCOUT_*` configuration and persistent discovery paths are set. It reconciles committed captures into cases; the default remains disabled. Its source status distinguishes unavailable or failed collection from a successful cycle. No additional legacy collector is implicitly included.
