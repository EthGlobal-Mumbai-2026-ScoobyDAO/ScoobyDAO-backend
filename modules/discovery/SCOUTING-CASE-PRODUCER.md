# Source-grounded scouting producer and backend integration

`scouting_brief.scouting_brief(record, evidence_root, run_id, as_of=None)` is an additive producer proposal for the actionability-ranked Cases flow. Input is a trusted live frozen candidate v0.1 plus local hash-addressed snapshots; output is `scooby.scouting-brief/1-proposal` with the candidate identity, run/policy/screening snapshot identity, scouting origins, source observations, deterministic group results, coverage and routing rationale. It makes no external calls, does not mutate the candidate/report schema, does not authorize a person and does not dispatch work.

- A `new_pool_lead` is shown only if the linked GeckoTerminal capture hashes correctly, is associated with the same chain/address, and matches the expected source path. Its observation time is unknown, its capture time is shown, and it is explicitly only a discovery origin.
- Fresh GoPlus Token Security captures must be bound to the candidate chain/address and matching expected endpoint, be no more than one hour old, not future-dated, and pass content-hash/path checks. The response source is provider-reported, not independently authenticated or a consensus proof. Positive specific security flags may justify human review, are labeled `provider_reported_unverified`, carry their capture reference/time and contribute **zero** gate votes. A provider statement that source code is unavailable is shown as a coverage gap; it does not itself recommend investigation. Missing, stale, invalid and failed capture is unavailable, never a clean result.
- Registered G07 and G09 verifiers independently produce deterministic group rows via `screening_result`; unsupported, held and unknown data remain visible. Each genuinely triggered group has one vote, shared evidence artifacts cannot independently count across groups, and the exact four-group policy is unchanged. Source reports, multiple flags about a common mechanism, and Reddit allegations do not create any votes.
- `routing.recommendation` is `auto_eligible` only for four verified groups; `human_review_required` for any verified group or specific fresh provider-reported concern below threshold; `monitor` otherwise. `reason_codes` state why, including provider unavailability when appropriate. This routing is a proposed deterministic input, not an authenticated authorization or a probability of wrongdoing. Backend must own user-facing order by overall actionability, allow one bounded investigation after confirmed World ID for the human path, and auto-start policy-qualified research without a click. Both routes must execute the same real investigation/report producer and link the report back to its case. Recompute policy/identity/freshness on the server immediately before dispatch.

## Current gap and local evidence

Only G07 LP sample concentration and a narrowly scoped G09 price-move check are enabled, both for Ethereum Uniswap V2/WETH. G02 transfer restriction has an experimental local fork executor but no verified real-EVM execution or registered vote. G01 control, G03 holders, G04 liquidity removal and G05 execution depth still need independent method/data validation; G06/G08/G10/G11/G12 are held. Base is not covered by these verifiers. Therefore no currently genuine case can meet four groups; do not add placeholders or fabricate an auto-qualified example. The backend must integrate source polling, durable evidence/restart handling, unified real research/report producer and case/report lineage. World ID must authorize the human research action separately from final publication. No fresh source or paid/model requests were used for this producer.

A read-only evaluation of the four existing local pilot records produced four monitoring recommendations: each retained a source-linked new-pool origin, but current on-chain concern results and/or security-provider captures were unavailable/stale. No new token, current security conclusion or completed investigation follows from that check. Synthetic tests exercise provider warning vs verified vote, stale/tampered/identity-mismatched evidence, missing-source ambiguity and source-linked pool origin; they are not real incidents.
